# NimbuStats

An Android app for tracking daily life — expenses first, then habits, limits,
and goals.

The premise: daily expense tracking fails because of friction. So most expenses
record themselves from bank SMS, the rest take under five seconds, and the
payoff is analysis deep enough to change behavior — three independent labeling
dimensions on every expense (a category tree, nestable tags, and an optional
necessity × satisfaction verdict), freely cross-tabulated.

Farsi/Jalali and English/Gregorian, both switchable. Local-first SQLite. No
backend.

## Status

Pre-implementation. Phase 0 is planned in full; nothing is built yet.
